# Fetangov Hub

Welcome to **Fetangov Hub** – a modern, TypeScript-powered application delivering robust functionality and seamless user experience.

## 📋 Overview

Fetangov Hub is a contemporary web application built with cutting-edge technologies to provide efficient solutions and optimal performance. The project leverages TypeScript for type-safe development, ensuring code reliability and maintainability.

## 🛠️ Tech Stack

- **TypeScript** (96.7%) - Type-safe development language
- **React** - UI library for building interactive components
- **Vite** - Next-generation frontend build tool
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn-ui** - High-quality component library
- **CSS** (1.5%) - Custom styling and layout

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/Abdulfetah-Tech/fetangov-hub.git
cd fetangov-hub
```

2. **Install dependencies:**
```bash
npm install
# or
yarn install
```

3. **Start the development server:**
```bash
npm run dev
# or
yarn dev
```

The application will be available at `http://localhost:5173` (Vite default)
